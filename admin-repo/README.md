# magnachip-website-admin\n\nThis repository holds admin-side helpers.\n\nWorkflow: push files under the pending/ folder (preserve relative paths). The GitHub Actions workflow will copy these files into the target repo (sean2019391/magnachip-website) and open a Pull Request.\n\nUsage:\n1. Add a repository secret named REPO_WRITE_TOKEN (a PAT with repo scope) to this repository's Settings → Secrets.\n2. Create or update files under pending/, e.g. pending/public/data/articles.json, commit and push to this repo's main branch.\n3. The workflow will run and open a Pull Request on the website repo.\n
