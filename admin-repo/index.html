Magnachip Admin (Editor)

Repo: magnachip-website-admin

This in-browser admin lets you edit files under pending/. You must paste a GitHub Personal Access Token (PAT) with repo scope into the token field below to read and save files. The token is used only by your browser session ? it is not sent to any server here.

You can also change targetPath in the UI to edit other pending files.
